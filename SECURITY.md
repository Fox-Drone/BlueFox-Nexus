# 🔐 Security Policy

## Supported Versions

BlueFox-Nexus is under active development.  
Security updates are only provided for the latest `main` branch.

| Version        | Supported          |
|----------------|--------------------|
| main (latest)  | :white_check_mark: |
| older releases | :x:                |

---

## 🚨 Reporting a Vulnerability

Please report all security vulnerabilities using **GitHub Security Advisories**:

👉 https://github.com/Fox-Drone/BlueFox-Nexus/security/advisories/new

---

## ⚠️ Out of scope

The following are considered **out of scope**:

- Misconfigurations in user environments
- Issues in third-party dependencies without an exploit in BlueFox itself
- Denial of Service attacks without security impact
- Social engineering attacks
- Physical access attacks
- Vulnerabilities in unsupported or modified versions of the project

---

## 🙏 Thanks

We appreciate responsible disclosure efforts that help improve BlueFox security.
