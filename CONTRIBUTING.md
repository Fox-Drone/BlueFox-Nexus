# 🤝 Contributing to BlueFox-Nexus

Thank you for your interest in contributing to BlueFox-Nexus.

This project is currently in early development, so contributions are welcome but may evolve rapidly.

---

## 📌 Guidelines

- Keep code consistent with the existing Rust architecture
- Follow modular and clean design principles
- Avoid introducing unnecessary complexity
- Ensure changes align with the SIEM / observability focus

---

## 📬 Submitting changes

1. Fork the repository
2. Create a feature branch
3. Commit your changes clearly
4. Open a pull request with a detailed description
